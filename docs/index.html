Проекты

   
       
         

Noctis

         

Форк Telegram для Android. Собрал стоковый клиент, поменял иконки и название, добавил свои настройки и открыл скрытые функции в интерфейсе.

       
       
         

ESP32

         

Практика с железом: передаю состояние кнопки по ESP-NOW между C3 и S3, разбираюсь с GPIO и подтяжками, работаю в PlatformIO и решаю проблемы с версиями API.

       
       
         

S.A.F.D.

         

Модульная носимая система. Отдельные узлы на ESP32 обмениваются командами и постепенно объединяются в одну экосистему. Пока в разработке.

       
       
         

DataValidator

         

Небольшая C++ библиотека для проверки email, IP и телефона. Сборка через CMake, есть header-only вариант, README и релизы.

       
       
         

Интерпретатор bimbimbambam

         

Учебный интерпретатор: разбирает выражения, считает результат и обрабатывает ошибки. Интересно, как текст превращается в дерево и код.
